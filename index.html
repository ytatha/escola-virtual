🐍 Python Básico

Python é uma linguagem de programação versátil, fácil de aprender e amplamente utilizada no mercado. Com ela você pode criar desde scripts simples até aplicações web, análise de dados e inteligência artificial.

O que você vai aprender:

  • Variáveis e tipos de dados
  • Operadores e expressões
  • Estruturas condicionais (if/else)
  • Laços de repetição (for/while)
  • Funções e módulos
  • Listas, tuplas e dicionários
🐍 Python é uma excelente escolha para iniciantes! Na Escola Virtual você encontra o curso Python Básico com certificado gratuito.

ℹ️ Sobre a Escola Virtual

A Escola Virtual é uma plataforma de educação online gratuita criada pela Fundação Bradesco. Oferece cursos livres de Formação Inicial e Continuada (FIC) nas áreas de Administração, Contabilidade, Desenvolvimento Pessoal, Educação e Tecnologia.

Os cursos são autoinstrucionais, com certificado digital válido por 2 anos. Para se inscrever, basta criar uma conta no site oficial: www.ev.org.br.

Site demonstrativo criado para fins educacionais. Todos os direitos sobre os cursos pertencem à Escola Virtual - Fundação Bradesco.
